# Operation 유스케이스별 객체 관계

구현 클래스보다는 외부에서 사용하는 인터페이스와 도메인 모델을 표시합니다.
화살표에는 전달하는 요청을 한글로 쓰고, 실제 메서드 이름은 괄호 안에 표시합니다.

## Operation 내부 모듈

```mermaid
flowchart LR
    JOB["Job 관리<br/>(operation.job)"]
    TASK["Task 실행 관리<br/>(operation.task)"]
    WORKFLOW["실행 순서 조정<br/>(operation.workflow)"]
    SHARED["공용 외부 연동<br/>(operation.shared)"]

    WORKFLOW -->|"Job 상태 변경 요청"| JOB
    WORKFLOW -->|"다음 Task 생성 요청"| TASK
    TASK -->|"연결된 Job 결과 전달 (LinkedJobProgress)"| WORKFLOW
    JOB -->|"DB와 감사 기능 요청"| SHARED
    TASK -->|"Agent와 DB 기능 요청"| SHARED
    WORKFLOW -->|"DB와 인증 정보 요청"| SHARED
```

`Task → Workflow` 연결은 Workflow 구현체를 직접 호출하는 관계가 아닙니다.
Task가 선언한 요청 인터페이스인 `LinkedJobProgress`를 Workflow가 구현합니다.

## 1. Job 생성과 조회

```mermaid
flowchart LR
    CLIENT[운영 요청자]
    JOBS["Job 생성과 조회<br/>(JobOperations)"]
    DATABASES["관리 DB 조회<br/>(DatabaseReader)"]
    CONFIGURATIONS["설정 변경 가능 여부 확인<br/>(ConfigurationChange)"]
    STORE["Job 저장소<br/>(JobStore)"]
    JOB["운영 Job<br/>(OperationJob)"]
    AUDIT["감사 기록<br/>(AuditWriter)"]

    CLIENT -->|"백업 Job 생성 (createBackupJob)"| JOBS
    CLIENT -->|"설정 점검 Job 생성 (createConfigurationCheckJob)"| JOBS
    CLIENT -->|"설정 변경 Job 생성 (createConfigurationApplyJob)"| JOBS
    CLIENT -->|"Job 하나 조회 (getJob)"| JOBS
    CLIENT -->|"Job 목록 조회 (getJobs)"| JOBS

    JOBS -->|"작업 대상 DB 조회 (findDatabase)"| DATABASES
    JOBS -->|"설정 변경 가능 여부 확인 (validate)"| CONFIGURATIONS
    JOBS -->|"Job 생성 (create)"| JOB
    JOBS -->|"중복 Job 조회 (findDuplicate)"| STORE
    JOBS -->|"Job 저장 (save)"| STORE
    JOBS -->|"Job 조회 (findById, findLatest)"| STORE
    JOBS -->|"Job 생성 기록 (record)"| AUDIT
```

## 2. Worker의 Job 가져오기와 실행 시작

```mermaid
flowchart LR
    SCHEDULER[Job 확인 스케줄러]
    CLAIM["Job 가져오기<br/>(JobClaim)"]
    WORKER_STATE["Worker 종료 상태 확인<br/>(WorkerState)"]
    STORE["Job 저장소<br/>(JobStore)"]
    JOB["운영 Job<br/>(OperationJob)"]
    BACKUP["백업 Task 요청<br/>(BackupTasks)"]
    CONFIG_CHECK["현재 설정 점검<br/>(ConfigurationCheck)"]
    CONFIG_CHANGE["설정값 변경<br/>(ConfigurationChange)"]
    EXECUTION["Job 종류별 실행<br/>(JobExecution)"]
    AUDIT["감사 기록<br/>(AuditWriter)"]

    SCHEDULER -->|"실행할 Job 요청 (claimJob)"| CLAIM
    CLAIM -->|"종료 중인지 확인 (isShuttingDown)"| WORKER_STATE
    CLAIM -->|"실행 가능한 Job 조회 (findClaimable)"| STORE
    CLAIM -->|"Job 실행권 설정 (start)"| JOB
    CLAIM -->|"Job 종류에 맞는 실행 요청 (execute)"| EXECUTION
    EXECUTION -->|"백업 Task 생성 요청 (createBackupTask)"| BACKUP
    EXECUTION -->|"현재 설정 점검 요청 (check)"| CONFIG_CHECK
    EXECUTION -->|"설정값 변경 요청 (apply)"| CONFIG_CHANGE
    EXECUTION -->|"실행 시작 결과 반환 (JobExecutionOutcome)"| CLAIM
    CLAIM -->|"Job 상태 반영 (succeed, fail, retry)"| JOB
    CLAIM -->|"Job 실행 기록 (record)"| AUDIT
```

## 3. Worker의 Job 결과 보고

```mermaid
flowchart LR
    WORKER[Worker]
    REPORTS["Job 결과 보고<br/>(JobReports)"]
    STORE["Job 저장소<br/>(JobStore)"]
    JOB["운영 Job<br/>(OperationJob)"]
    AUDIT["감사 기록<br/>(AuditWriter)"]

    WORKER -->|"Job 성공 보고 (succeedJob)"| REPORTS
    WORKER -->|"Job 실패 보고 (failJob)"| REPORTS
    REPORTS -->|"Job 조회 (findById)"| STORE
    REPORTS -->|"성공 상태 반영 (succeed)"| JOB
    REPORTS -->|"실패 또는 재대기 반영 (fail, retry)"| JOB
    REPORTS -->|"Job 결과 기록 (record)"| AUDIT
```

## 4. Agent의 Task 가져오기

```mermaid
flowchart LR
    AGENT[현장 Agent]
    CLAIM["Task 가져오기<br/>(TaskClaim)"]
    AGENTS["Agent 확인<br/>(AgentReader)"]
    STORE["Task 저장소<br/>(TaskStore)"]
    TASK["운영 Task<br/>(OperationTask)"]
    AUDIT["감사 기록<br/>(AuditWriter)"]

    AGENT -->|"다음 Task 요청 (claimNext)"| CLAIM
    CLAIM -->|"Agent와 Token 확인 (findAgent, matchesToken)"| AGENTS
    CLAIM -->|"가장 오래된 대기 Task 잠금 조회 (findNextForUpdate)"| STORE
    CLAIM -->|"Task 실행 시작과 실행권 설정 (claim)"| TASK
    CLAIM -->|"Task 가져오기 기록 (record)"| AUDIT
```

## 5. Task 실행권 갱신

```mermaid
flowchart LR

    LEASE -->|"Task 조회 (findById)"| STORE
```

```mermaid
    TASK_CREDENTIAL -->|"인증 정보 복호화 (resolve)"| CREDENTIALS
```
